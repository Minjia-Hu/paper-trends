# 交互探索：时间窗口与论文证据

应用将两种阅读任务分开：**报告**用于快速理解结论，**探索**用于改变问题、检查证据。探索模式使用已有真实语料，无须额外请求或外部模型。

## 中文与英文

应用顶部可切换“中文 / English”。未指定语言时跟随浏览器首选语言；显式的 `?lang=zh` 或 `?lang=en` 优先，并随会议搜索、时段及视图切换保留。例：`http://localhost:8501/?conference=ectc&lang=zh`。

报告正文、趋势解读、计数规则、图表提示和论文详情控件提供中文。论文标题、摘要、技术词、会议及机构名称保留原文。中英文共享同一次分析结果；语言只影响展示，不改变计数、词形匹配或论文示例。

静态生成命令同时输出英文的 `<slug>.html` / `index.html` 和中文的 `<slug>.zh.html` / `index.zh.html`，页面顶部可互相切换。JSON 数据仍只输出一份，使用原始字段名。

## 使用方式

- 报告模式按“摘要—趋势—主题—机构与地域—方法”组织。正文只展示最有解释力的图表，完整分析入口转入探索模式。
- 探索模式按任务分为“趋势与证据、主题分析、机构分析、跨会议比较、论文与导出”。切换任务时保留会议、时段和语言。
- 默认显示顶部所选的完整时段。拖动 From / To 选择范围；两端可重合成单年。Play years 移动整个窗口；全时期状态下播放逐年快照。再次点击暂停，Full period 恢复完整范围。
- 选择一个短语，或点击右侧榜单中的短语。曲线显示全年份，浅色区域标出当前窗口。
- 切换 Title only、Title or repeated、Any mention。大号百分比是窗口内总命中数 / 总记录数；折线是逐年比例；旁边的变化量比较窗口两端，以百分点表示。
- 机构、主题、短语榜单和论文例子都跟随时间与计数规则变化。论文卡片注明标题命中、摘要重复或单次提及，可以展开完整摘要，也可以打开 DOI。
- 报告中的技术词详情提供“在探索模式中查看时间变化”入口，并保留当前会议、时段和关键词。
- 通过“查找其他关键词”提交由两至三个英文单词组成的短语，会将其加入同一个交互区。连字符、大小写和缩写按语料统计规则归一化；低频词也能查询，未命中时显示空结果，不自动改选其他词。
- “全部匹配论文与导出”提供完整结果，每页 20 篇，可按时间或被引次数排序。它与曲线共用关键词、时间窗口和计数规则；CSV 包含所有页的结果，并注明筛选条件。
- 顶部自选年份通过重复的 `years` 参数保存，例如 `period=custom&years=2017&years=2025`；切换报告、探索、任务页和语言时保留两端年份。观测台内的临时时间窗口和规则在离开页面后重置。
- 机构分析中的“深入分析机构”按需展示前 8 家机构的排名变化、主题构成及对应数据表；开关控制是否合并上级机构，所有机构图表保持一致。单年仍可看主题构成，不展示排名变化。
- “论文与导出”支持检索标题和摘要、按时间或被引次数排序，并导出当前筛选结果；完整语料和汇总表仍可单独导出。

## 数据口径

三类角色互斥，优先级为标题、摘要重复、摘要单次。同一篇论文对同一个短语只计一次，缩写规则与原报告一致。

| 模式 | 包含角色 |
|---|---|
| Title only | 标题 |
| Title or repeated | 标题 + 摘要重复，与默认报告一致 |
| Any mention | 标题 + 摘要重复 + 摘要单次 |

候选短语最多 20 个，来自原报告上升、新出现、下降和高频词及当前搜索词，按稳定顺序去重。榜单只比较这组候选词；搜索不受这个候选列表或排名最低频次限制。

机构与主题计数使用全部命中记录。机构在论文内去重，但不同机构可同时获得一篇论文的计数；主题使用整个报告时期拟合的 NMF 分配，并不在每次拖动后重新拟合。

只有展示的论文例子进行了限量：每个短语、年份和角色保留最多三篇高被引论文。例子在所选范围与角色中按引用数排序，可加载更多。界面明确标明它们不是完整结果集，也不是代表性随机样本。总数从所有记录计算，不从这些例子估算。完整列表与 CSV 使用同一次角色判定得到的全部匹配 ID；只增加标题、年份、DOI 和引用数等列表元数据，完整摘要仍仅随示例载入。

## 边界与验证

- 缺失年份的分母为零：图线断开，显示 `—` 和无记录状态，不伪造 0% 份额。
- 只用标题分析的报告：只提供标题模式，禁用另外两种规则，并解释原因。
- 单年语料：禁用时间滑块和播放，不计算升降幅度。
- 没有合格短语：报告仍正常显示；探索模式说明当前时段没有可用短语，不显示空观测台。
- 原始标题、摘要和机构名称均转义；论文链接只允许 DOI resolver URL。
- 键盘可操作原生下拉菜单、滑块、按钮和摘要展开；有焦点样式，尊重减少动画设置。手动改变选择、页面隐藏或退出时停止播放。
