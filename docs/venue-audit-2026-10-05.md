# 候选会议覆盖审计 · 2026-10-05

**后续进展：ICASSP、EMBC、IEEE S&P、GLOBECOM 已完成全量查询和清理，并接入预设。** 本地新增 46,076 篇记录，均覆盖 2016–2025；下方审计表保留接入前的查询口径。清理后的结果见文末。

建议第一批新增 **ICASSP、EMBC、IEEE S&P、GLOBECOM**。INFOCOM 可作为第二批，默认分析截至 2024 年。ICC、ICSE、ECCE 需要先解决同缩写会议混入；CHI、ACL、NeurIPS、ICML 需要完善会议身份和历年 proceedings 的匹配，不能靠补一个缩写预设解决。

截图里“保留半导体深度，再扩展几个会议社区”的方向合理。不过，“IEEE 会议有规整前缀，因此一次就能抓全”的判断不成立：前缀可能改名，也可能被多个会议共用。摘要覆盖率高只说明命中的记录有摘要，不代表抓对了会议或抓全了年份。

## 查询范围与口径

- 时间范围：2016–2025；查询日期为北京时间 2026-10-05。
- 数据源只有 OpenAlex；先运行项目现有解析器，再查询年份分布、`has_abstract:true` 的年份分布和固定种子的元数据样本。
- 对 IEEE 前缀分别查询紧随缩写的 `.`、`0` 至 `9`，排除 ICCV、ICCAS、SPW 等不同缩写。11 个分区互不重叠，可相加。该操作仍不能排除共用同一缩写的会议。
- 每个非空分区最多抽样 200 条，检查 DOI 边界、来源名称和前言等非论文记录。**这是分层样本，不能将样本中某会议的比例直接当成总体比例。**
- 下表的数值是筛选范围内的 OpenAlex 记录数，尚未全量去除非论文记录，也没有用官方 proceedings 总数测召回率；不是完整会议论文数。来源筛选与 DOI 筛选的结果不相加。
- 本次 API 对 `doi_starts_with` 的管道 OR 查询返回了错误的零结果，所以改为独立查询后合并；没有把这些零结果用于结论。

方法依据：[OpenAlex filters](https://help.openalex.org/api/filtering/)、[grouping](https://help.openalex.org/api/grouping/)。可复核的查询条件、计数和样本来源汇总见 [JSON 快照](venue-audit-2026-10-05.json)。

## 关键证据

**边界过滤解决不了同缩写冲突。** 例如这些 DOI 均通过项目现有规则，但属于另外的会议：

- [10.1109/ICC47138.2019.9123208](https://doi.org/10.1109/ICC47138.2019.9123208)：Sixth Indian Control Conference。
- [10.1109/ICSE49846.2020.9166872](https://doi.org/10.1109/ICSE49846.2020.9166872)：International Conference on Semiconductor Electronics。
- [10.1109/ECCE57851.2023.10101624](https://doi.org/10.1109/ECCE57851.2023.10101624)：International Conference on Electrical, Computer and Communication Engineering。

**一个前缀不一定覆盖历年。** `globecom` 在 2016、2017、2018 各只有 1 条；旧前缀 `glocom` 同期分别有 915、1,028、999 条。现有解析器只返回 `globecom`，因而仅凭解析成功会漏掉早期年份。

**有十个年份不等于十年完整。** INFOCOM 的分区计数为：304、296、316、295、274、259、231、258、263、26。2025 年的骤降应首先视作覆盖缺口，不能解释成会议萎缩。

**现有缩写回退会给出错误的确定答案。** 修复前 `CHI` 返回 `TAP CHI SINH HOC`，`ACL` 返回 Findings，并根据 `10.18653/v` 显示约 52,847 条。这不是 ACL 主会的数量。

## 本轮已修复

1. 缩写在 IEEE 前缀探测失败后，不再接受仅包含该短字符串的来源名称。CHI、ACL 现在提示无法可靠识别，并引导输入全名；Interspeech 等名称本身就是单词的会议仍可按去除年份后的精确名称匹配。
2. 从来源样本推断的 DOI 前缀必须能通过抓取器的边界规则，不再把 `10.18653/v1/...` 截成 `10.18653/v` 并扩大显示数量。
3. 更新 Streamlit 的解析缓存函数，避免继续复用旧解析结果。新增三项回归测试，完整测试集 74 项通过；用本轮真实 API 缓存重放，确认 CHI、ACL 的错误匹配已消失。

这些修复不解决 ICC、ICSE、ECCE 的同缩写冲突，也不补齐 CHI 等会议的历年来源。上面的推荐排序已经考虑这些剩余问题。

## 接入顺序

1. 全量抓取 ICASSP、EMBC、IEEE S&P、GLOBECOM 的 2016–2025 数据，沿用去重、非论文记录过滤及年度覆盖检查；为 GLOBECOM 显式配置两个前缀。
2. 检查各领域生成的关键词和主题报告，再将通过检查的会议加入按领域分组的首页。领域是否够广应由可用报告证明。
3. INFOCOM 单独处理最新年覆盖问题；其余会议先建立明确的会议身份、年度 proceedings 和前缀对应关系。

执行审计：

```bash
.venv/bin/python -m scripts.audit_venues
# 或只查指定会议；同一缓存会复用，重新取快照前先移走旧缓存目录
.venv/bin/python -m scripts.audit_venues icassp embc
```

原始响应和样本保存在被 Git 忽略的 `data/venue-audit/`；报告快照保留修复前的解析结果作为证据。没有把查询计数当作已抓取的完整语料。

抓取沿用来源与 DOI 前缀合并、OpenAlex ID 去重、前言等非论文记录过滤，再按 DOI 合并重复记录；ICASSP 另剔除两条无正文的会议论文集目录。原始抓取文件保留在 `data/venue-audit/fetched-original/`，清理记录在 `data/venue-audit/onboarding-quality.json`。

GLOBECOM 的 2016–2018 年分别保留 911、1,025、997 篇，确认旧前缀已补入；2025 年摘要覆盖仍为 85.2%，趋势解读需注意这个缺口。这是现有 OpenAlex 查询覆盖范围内的语料，未以官方论文集逐篇核对召回率。

首页新增信号处理、生物医学工程、安全和通信四个领域分组，预设共 17 个；静态站点同步包含这些报告。跨领域背景词表也已用新增语料重建。

验收结果：80 项测试通过；19 份静态报告及首页全部重新生成，内联 JavaScript 语法、图表挂载目标、本地链接，以及展示短语与详情面板的年度计数均已检查。新增预设的首页入口和搜索到缓存报告的流程由 AppTest 覆盖。浏览器连接不可用，未做视觉验收。

内容抽查中，IEEE S&P 的上升词包括大语言模型、后量子密码、投毒攻击和后门攻击；GLOBECOM 包括联邦学习、可重构智能表面、低轨卫星和语义通信。背景表仍会过滤深度学习等跨领域技术词，因此这些列表表示当前统计规则下的相对变化，并非各领域全部热点。
