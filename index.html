Your own conference

Two commands give any conference indexed by OpenAlex a page like these:

uv run python -m paper_trends fetch "Electronic Components and Technology Conference" --doi-prefix 10.1109/ectc --years 2016-2025 --name ectc
uv run python -m paper_trends report data/ectc.jsonl --years 2016-2025 --out site

For live exploration — pick a term, see the papers behind it, compare venues — run the interactive app: uv run streamlit run app.py. Source and instructions: github.com/Minjia-Hu/paper-trends.
