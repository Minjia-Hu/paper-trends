探索其他会议

用以下两条命令，为 OpenAlex 收录的会议生成同样的中英文报告：

uv run python -m paper_trends fetch "Electronic Components and Technology Conference" --doi-prefix 10.1109/ectc --years 2016-2025 --name ectc
uv run python -m paper_trends report data/ectc.jsonl --years 2016-2025 --out site

如需交互探索、阅读关键词对应论文或比较会议，启动应用： uv run streamlit run app.py. 代码与说明： github.com/Minjia-Hu/paper-trends.
