# paper-trends identity

The selected direction is **01 — classic book editorial**, shown in
`logo-01-reference.png`. This concept preview was made with the built-in
image generation tool and selected by the project owner.

The production mark is redrawn as font-independent SVG paths in
`paper_trends/report/static/logo.svg`, paired with the website's existing
Newsreader wordmark. The app and static HTML exports share this asset.
`paper_trends/report/static/favicon.svg` uses the same silhouette with slightly
stronger details and an ivory background for readability in browser tabs.

Design brief: a readable lowercase **pt** ligature with classic transitional
serifs, moderate stroke contrast, an open p counter and a restrained t foot.
A short red t crossbar is the signature accent. Pair with the lowercase
`paper-trends` serif wordmark. Use charcoal `#1B1B1B`, vermilion `#E3120B`,
and warm ivory `#FCFBF8`; avoid shadows, gradients, borders and ornamental
swashes. Keep the identity quiet and consistent with the academic editorial
page design.
